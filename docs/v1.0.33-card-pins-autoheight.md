# v1.0.33 candidate — pinned cards, auto height, Antigravity compact summary

## 카드 상단 고정

- 각 토큰 플랫폼/계정 카드 오른쪽 위에 작은 고정핀 버튼을 표시합니다.
- 고정한 카드는 공급자 그룹보다 위의 `고정` 영역으로 이동합니다.
- 여러 카드를 고정하면 고정한 순서를 유지합니다.
- 다계정 카드는 `instanceKey`를 사용해 특정 계정 카드만 정확히 고정합니다.
- 카드 이동 후에도 인증 이메일/login/ID가 다른 카드에 잘못 붙지 않도록 계정 identity 연결을 key 기반으로 변경했습니다.

## 위젯 높이 자동 조절

- 설정 > 표시에 `높이 자동 조절` 토글을 추가합니다.
- 켜짐: 카드/설정 내용에 따라 기존 content-driven height 조절을 사용합니다.
- 꺼짐: 현재 높이를 manual height로 저장해 이후 자동 resize가 사용자 높이를 덮어쓰지 않습니다.
- 다시 켜면 manual height만 제거하고 사용자가 조절한 너비는 유지합니다.
- 테두리를 세로 방향으로 직접 조절해 manual height가 있는 경우 토글은 꺼짐 상태로 표시됩니다.

## Antigravity compact 모드

- 자세히 모드에서는 Gemini 및 Antigravity 요금제 내부 Claude/GPT quota를 기존처럼 모두 표시합니다.
- 간단 모드의 대표 퍼센트/리셋은 Gemini quota가 존재하면 Gemini 범위에서만 선택합니다.
- 따라서 더 낮은 Claude/GPT 주간 한도가 Antigravity 카드의 대표값으로 잘못 표시되지 않습니다.
- 기본 `agy` 조회와 AGM 다계정 경로에 같은 규칙을 적용합니다.

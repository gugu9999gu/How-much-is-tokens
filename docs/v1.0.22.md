# v1.0.22 — 격리 다계정 표시

v1.0.22는 v1.0.21의 계정별 `accountKey` 기반을 실제 다계정 표시로 확장합니다.

## 지원 범위

추가 프로필을 동시에 표시할 수 있는 provider:

- Codex / ChatGPT (`CODEX_HOME`)
- Claude Code (`CLAUDE_CONFIG_DIR`)
- Grok / Grok Build (`GROK_HOME`)

기존 기본 로그인은 그대로 유지됩니다. 추가 프로필이 하나 이상 등록되면 기본 로그인 카드에는 `기본 계정` 라벨이 붙고, 등록한 프로필은 설정한 이름으로 별도 카드가 생성됩니다.

예:

```text
OpenAI
├─ Codex · 기본 계정
└─ Codex · GPT 2번

Anthropic
├─ Claude · 기본 계정
└─ Claude · Claude 업무

xAI
├─ Grok · 기본 계정
└─ Grok · Grok 2번
```

각 카드에는 해당 계정의 quota, 리셋 시각, 크레딧/잔액이 독립적으로 표시됩니다. Claude의 Fable/model-scoped quota와 Usage Credits도 계정별로 분리됩니다.

## 프로필 준비

위젯이 인증 파일을 복사하거나 계정 토큰을 다른 프로필로 옮기지 않습니다. 각 CLI가 자신의 격리 디렉터리에 정상 로그인한 상태여야 합니다.

PowerShell 예시:

### Codex

```powershell
$env:CODEX_HOME = "D:\AI-Profiles\codex-2"
codex login
```

### Claude Code

```powershell
$env:CLAUDE_CONFIG_DIR = "D:\AI-Profiles\claude-work"
claude
```

해당 프로필에서 로그인을 완료한 뒤 종료해도 됩니다.

### Grok

```powershell
$env:GROK_HOME = "D:\AI-Profiles\grok-2"
grok
```

## 위젯 등록

설정 → **다계정 프로필 → 격리 로그인 프로필**에 한 줄씩 입력합니다.

형식:

```text
provider|표시 이름|설정 디렉터리
```

예:

```text
codex|GPT 2번|D:\AI-Profiles\codex-2
claude|Claude 업무|D:\AI-Profiles\claude-work
grok|Grok 2번|D:\AI-Profiles\grok-2
```

지원하지 않는 provider, 상대경로, 같은 provider의 중복 경로는 저장 시 제거됩니다. 현재 기본 프로필과 같은 경로를 다시 등록해도 중복 카드가 생성되지 않습니다.

## 격리 방식

프로필별로 다음 항목을 분리합니다.

- CLI 인증/config 디렉터리
- provider runtime instance ID
- persistent usage/credit cache
- 화면의 account label
- Codex app-server 실행 환경

프로필 ID는 `provider + 정규화된 config path`를 SHA-256으로 해시한 값에서 생성합니다. raw OAuth token이나 account ID를 프로필 설정의 식별자로 사용하지 않습니다.

명시적 프로필의 stale cache는 다른 계정의 provider-wide legacy cache로 fallback하지 않습니다. 따라서 GPT 1번의 이전 quota가 GPT 2번 카드에 나타나는 것을 방지합니다.

## Codex 자동 리셋 안전 정책

v1.0.22의 추가 Codex 프로필은 quota/credits/reset ticket **조회만** 합니다.

기존 `Codex 한도 자동 리셋` 글로벌 토글은 기본 Codex 계정에만 적용됩니다. 추가 계정까지 한 번에 opt-in시키면 의도하지 않은 계정의 banked reset을 소비할 수 있기 때문입니다.

추가 프로필별 자동 리셋은 향후 계정별 automation policy와 함께 별도 설정으로 추가하는 것이 안전합니다.

## 아직 포함하지 않는 범위

이번 단계에는 다음 기능을 넣지 않습니다.

- 한도 도달 시 1번 계정 → 2번 계정 자동 실행 전환
- 이미 실행 중인 ChatGPT/Codex Desktop 세션의 강제 계정 변경
- Cursor/Copilot/OpenRouter의 여러 credential을 동시에 등록하는 UI
- 계정별 우선순위/라운드로빈/잔여량 기반 request router

이후 Smart Routing은 이번 버전의 profile/runtime/cache 격리를 그대로 사용해 구현할 수 있습니다.

# How much is tokens v1.0.46

## macOS

- Apple Silicon용 `.app` / `.dmg` / `.zip`을 배포합니다.
- 이 Mac에서 빌드한 앱은 ad-hoc 서명되어 실행됩니다. 다른 Mac으로 옮기면 처음 한 번은 **우클릭 → 열기**를 사용하세요.
- 설정 → 계정 연결의 로그인을 macOS에서도 지원합니다. Codex, Claude Code, Grok, Cursor, Copilot, Antigravity는 Terminal에서 공식 CLI 로그인을 엽니다. OpenRouter는 기존 localhost OAuth를 그대로 사용합니다.

## CLI 자동 업데이트

- 설정 → 기본에 **CLI 자동 업데이트** 토글이 있습니다. 기본값은 꺼짐입니다.
- 켜면 Codex, Claude Code처럼 업데이트 가능하고 이 앱이 업데이트를 실행할 수 있는 설치된 CLI를 자동으로 최신 버전으로 올립니다.

Windows portable 실행 파일, macOS Apple Silicon 패키지, `SHA256SUMS.txt`를 함께 배포합니다.

# How much is tokens v1.0.51

## 간소화 보기: 주간 한도 갱신 일시

- 간소화된 사용량 카드에 **주간 한도 갱신 일시를 `11/30 18:00`처럼 짧게 표시**합니다.
- 일반 주간 한도 및 Fable 등 모델별 주간 한도에 각각 실제 제공된 갱신 시각을 표시합니다. Codex, Claude, Antigravity 등 각 공급자가 반환한 주간 한도에 동일하게 적용됩니다.
- 5시간 한도와 다른 사용량 항목에는 주간 갱신 날짜를 잘못 붙이지 않습니다.
- 날짜와 시각은 **실행 중인 PC의 현지 시간대**로 표시합니다.
- 갱신 시각이 누락되거나 유효하지 않거나 이미 지난 경우에는 갱신일을 만들어 표시하지 않습니다.
- 잔여 퍼센트·사용량 막대·기존 상세 보기·계정별 사용량 조회는 변경하지 않습니다.

## 검증 및 배포

- Windows 전체 회귀 테스트, Electron 간소화 UI smoke, 보안 저장소·Antigravity 연결 테스트와 portable 빌드에서 확인합니다.
- Windows 포터블 EXE와 SHA256 체크섬을 공개 릴리스에서 제공합니다.

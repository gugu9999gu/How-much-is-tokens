# How much is tokens v1.0.38

## 계정 정보와 간소화

- Claude 계정 ID를 다른 플랫폼과 같은 계정 칸에 표시합니다.
- 계정, 결제 또는 한도 갱신, 버전, 리셋 쿠폰이 플랫폼마다 같은 열에 놓입니다.
- 간소화 모드에서는 이 칸도 한 줄로 줄입니다. 한도 갱신, 버전, 쿠폰의 부가 설명은 숨기고 계정 ID는 남깁니다.

## 같은 계정으로 다시 로그인

- 로그아웃해도 프로필을 지우지 않습니다. 다시 로그인하면 새 번호 대신 기존 프로필을 사용합니다.
- 로그인 정보가 없는 빈 프로필이 있으면 그 프로필을 먼저 씁니다.
- 계정 ID가 같은 카드가 둘이면 하나만 남깁니다.
- OpenRouter도 같은 계정이면 새 키 프로필을 만들지 않고 기존 프로필에 다시 연결합니다.

Windows portable 실행 파일과 `SHA256SUMS.txt`를 함께 배포합니다.

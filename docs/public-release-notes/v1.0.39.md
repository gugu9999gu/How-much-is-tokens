# How much is tokens v1.0.39

## 계정 고정

- 토큰 카드의 핀을 누르면 그 계정이 목록 맨 위 고정 구역으로 올라갑니다.
- 다시 누르면 해제됩니다. 고정은 앱을 다시 열어도 유지됩니다.

## Cursor와 Grok Bot

- 두 카드는 같은 Cursor 로그인을 사용합니다. 이제 저장된 이메일과 표시 이름, Ultra 같은 요금제를 함께 보여 줍니다.
- Grok Bot 카드에 계정 이름이 Cursor로 보이던 표시를 없앴습니다.
- Grok Bot의 주간 퍼센트는 Grok Bot 전용 한도입니다. Cursor 모델 사용량과 숫자가 달라도 같은 계정입니다.

## 간소화

- 간소화 모드에서는 계정 상세, 결제일, 이용 기간, 버전, 리셋 쿠폰을 숨깁니다.
- 5시간, 주간 같은 한도는 이름, 막대, 퍼센트로 바로 보입니다.

Windows portable 실행 파일과 `SHA256SUMS.txt`를 함께 배포합니다.

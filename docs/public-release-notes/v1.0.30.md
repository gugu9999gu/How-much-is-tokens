# How much is tokens v1.0.30

## 반응형 토큰 그리드

- 위젯 너비를 드래그해 넓히면 공급자 토큰 카드가 사용 가능한 공간에 맞춰 자동으로 여러 열로 배치됩니다.
- 기본 폭에서는 1열을 유지하고, 넓은 창에서는 카드 최소 가독 폭을 지키면서 2열·3열 이상으로 자연스럽게 확장됩니다.
- 다중 quota의 원형/숫자 표시도 카드 폭에 따라 자동으로 열 수를 조절합니다.
- 다시 창을 좁히면 카드와 quota 셀이 자동으로 1열 또는 더 적은 열로 돌아갑니다.

## 설정 페이지 높이 잘림 수정

- 설정 영역에 남아 있던 520px 고정 최대 높이 제한을 제거했습니다.
- 위젯 높이를 수동으로 늘리면 설정 페이지가 헤더 아래의 전체 사용 가능 높이를 활용합니다.
- 설정 내용이 창보다 긴 경우 설정 영역 자체에서 스크롤하며, 최하단 설정 컨트롤까지 잘리지 않고 접근할 수 있습니다.
- 자동 높이 모드의 기존 intrinsic sizing은 유지하여 수동 높이를 사용하지 않는 경우에도 설정 페이지가 축소되지 않습니다.

## 검증

Windows Electron 실제 레이아웃 smoke에서 332px 1열, 620px 2열 이상, 900px 3열 이상 반응형 전환과 760px 높이에서 설정 영역이 기존 520px 제한을 넘어 전체 viewport를 사용하는 동작을 검증했습니다.

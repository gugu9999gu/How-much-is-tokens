# How much is tokens v1.0.49

## Claude 요금제 명칭 변경

- 기존 Max 5x는 **Max**, Max 20x는 **Ultra**로 표시합니다. Pro는 유지합니다.
- Claude Code OAuth의 subscriptionType=max 계정은 rateLimitTier=default_claude_max_20x를 함께 확인합니다.
- OAuth 프로필의 명시적 플랜명을 우선하고, Team 계정의 고성능 한도 등급만으로 Ultra라고 추정하지 않습니다.
- 구버전 캐시의 Max 5x/Max 20x 배지 이름도 새 이름으로 변경합니다.
- Ultra 계정에서 API가 5시간 한도를 반환하지 않으면 주간 한도만 표시하고, 실제로 반환된 한도는 숨기지 않습니다.
- 회귀 테스트 및 Windows portable 빌드 검증을 수행합니다.

## 공개 배포

How-much-is-tokens-releases에 Windows portable EXE, SHA256SUMS.txt, 릴리스 노트를 게시합니다.

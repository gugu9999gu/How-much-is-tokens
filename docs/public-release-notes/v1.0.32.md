# How much is tokens v1.0.32

## 생성형 미디어 다계정

- fal.ai, Higgsfield, Magnific, ElevenLabs, Stability AI에서 추가 계정을 프로필로 등록해 각각의 잔여량·크레딧·사용량을 별도 카드로 추적할 수 있습니다.
- 각 공급자 설정 카드에서 `+ API 계정`으로 추가 API Key 계정을 바로 만들 수 있습니다.
- 추가 프로필은 개별적으로 추적을 켜고 끄거나, 자격증명을 교체하거나, 연결을 삭제할 수 있습니다.
- 기존에 저장해 둔 단일 API Key는 `기본 연결`로 그대로 호환됩니다.

## 공식 MCP 연동

- 공식 hosted MCP가 확인된 공급자에는 `+ MCP 계정` 또는 `+ MCP 키`가 표시됩니다.
- Higgsfield는 공식 MCP OAuth 계정을 연결해 MCP의 credit/balance tool에서 잔여 크레딧을 우선 조회합니다.
- fal.ai는 공식 MCP에 API Key Bearer 방식으로 연결할 수 있습니다.
- Magnific 및 ElevenLabs는 공식 hosted MCP OAuth 연결을 지원하며, MCP가 잔여량을 제공하지 않는 경우 기존 공식 REST 사용량 API가 있는 범위에서만 fallback합니다.
- Stability AI는 공식 잔액 MCP endpoint를 확인하지 못했으므로 API Key 잔액 조회를 유지하며 MCP 기능을 임의로 표시하지 않습니다.

## 보안

- API Key, MCP OAuth token, PKCE verifier, dynamic client 정보는 모두 Electron OS `safeStorage`에 암호화합니다.
- `settings.json`에는 공급자/프로필 ID, 표시 이름, 연결 방식 같은 비민감 메타데이터만 기록합니다.
- 임의의 MCP URL 입력은 허용하지 않고 앱이 검증한 공급자별 공식 endpoint만 사용합니다.
- 동일한 API 자격증명을 같은 공급자에 중복 등록하는 것을 차단합니다. 서로 다른 API Key는 별도 사용량 추적 용도로 허용합니다.

## OpenRouter 프로필 UX 포함

- OpenRouter의 `+ API Key`, `+ 로그인`, 카드형 프로필 관리, 우선순위 변경, 추적 토글, 키 편집/삭제 기능을 함께 포함합니다.

Windows portable 실행 파일과 `SHA256SUMS.txt`를 함께 배포합니다.

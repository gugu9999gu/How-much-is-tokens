# How much is tokens v1.0.33

## 토큰 카드 상단 고정

- 각 토큰 플랫폼/계정 카드의 고정핀으로 자주 보는 카드를 위젯 최상단 `고정` 영역에 둘 수 있습니다.
- 여러 카드는 고정한 순서를 유지하며, 다계정 환경에서도 선택한 계정 카드만 정확히 고정됩니다.
- 카드가 이동해도 인증 이메일/login/ID가 다른 카드에 잘못 연결되지 않도록 계정 표시를 안정화했습니다.

## 위젯 높이 자동 조절

- 설정 > 표시에 `높이 자동 조절` 토글을 추가했습니다.
- 켜면 카드와 설정 내용에 맞춰 위젯 높이를 자동으로 조절합니다.
- 끄면 현재 높이를 유지하며 이후 콘텐츠 갱신이 사용자가 정한 높이를 덮어쓰지 않습니다.
- 다시 켜도 수동으로 조절한 위젯 너비는 유지됩니다.

## Antigravity 간단 모드 수정

- 간단 모드의 Antigravity 대표 퍼센트/리셋이 요금제 내부 Claude/GPT 주간 한도로 잘못 표시될 수 있던 문제를 수정했습니다.
- Gemini quota가 존재하면 Antigravity 대표값은 Gemini quota 범위에서 선택합니다.
- 자세히 모드에서는 기존처럼 Gemini와 Claude/GPT quota를 모두 확인할 수 있습니다.
- 기본 agy 계정과 AGM 다계정 경로 모두 같은 규칙을 적용합니다.

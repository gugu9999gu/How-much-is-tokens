# How much is tokens v1.0.27

## 로그인 창 표시 버그 수정

설정 → 계정 연결에서 로그인 버튼을 눌렀을 때 Windows 로그인 터미널/콘솔이 표시되지 않아 아무 반응이 없는 것처럼 보이던 문제를 수정했습니다.

- Codex, Claude, Grok, Cursor, Grok Bot, Copilot, Antigravity의 인터랙티브 로그인 콘솔을 Windows에서 숨기지 않도록 수정했습니다.
- 백그라운드 CLI 탐색/조회 프로세스는 기존처럼 숨김 상태를 유지합니다.
- 로그인 프로세스는 위젯과 독립적으로 실행되어 브라우저/CLI 인증 흐름을 정상적으로 진행할 수 있습니다.
- 동일 문제가 재발하지 않도록 Windows 로그인 launcher 회귀 테스트를 추가했습니다.

## v1.0.26 기능 포함

v1.0.26에서 추가된 생성형 미디어 API 공급자, 설정 UX 재설계, 안전한 자격증명 저장 기능을 모두 포함합니다.

Windows portable 실행 파일과 `SHA256SUMS.txt`를 함께 배포합니다.

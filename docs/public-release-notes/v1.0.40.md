# How much is tokens v1.0.40

## 고정 순서

- 고정한 계정 카드를 끌어 다른 고정 카드 위에 놓으면 순서가 바뀝니다.
- 바꾼 순서는 앱을 다시 열어도 유지됩니다. 핀 버튼은 그대로 고정과 해제만 합니다.

## Claude 추가 계정

- 설정에서 Claude 추가 계정 로그인을 마쳐도 카드가 사라지던 문제를 고쳤습니다.
- 다른 계정으로 로그인한 프로필은 다음 새로고침 때 다시 표시됩니다. 다시 로그인하지 않아도 됩니다.
- 기본 계정과 같은 계정으로 만든 중복 프로필은 이전과 같이 한 장만 남습니다.

Windows portable 실행 파일과 `SHA256SUMS.txt`를 함께 배포합니다.

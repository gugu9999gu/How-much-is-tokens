# How much is tokens v1.0.25

## 더 간단해진 계정 연결

설정 화면을 공급자별 **연결 상태 + 로그인 + 계정 추가** 중심으로 다시 구성했습니다.

기본 화면에는 다음만 표시됩니다.

- AI 공급자 계정 연결
- 항상 위에
- 시작 시 실행
- 빈 계정 숨기기

기존 표시 세부값, 다계정 경로, Smart Routing, API Key/PAT/cookie 직접 입력은 삭제하지 않고 **고급 설정** 안으로 이동했습니다.

## 공급자별 로그인

- **Codex**: ChatGPT 브라우저 로그인을 시작하는 `codex login`
- **Claude**: `claude auth login`
- **Grok**: `grok login`
- **Cursor**: `cursor-agent login` 우선, 설치 형태에 따라 `agent login`
- **Grok Bot**: Cursor 자격증명을 공유하므로 Cursor 로그인 사용
- **Copilot**: `gh auth login`; GitHub CLI credential manager의 로그인도 자동 재사용
- **Antigravity**: `agy`를 실행해 Google 로그인 시작
- **OpenRouter**: 수동 Key 붙여넣기 대신 localhost OAuth PKCE 로그인

각 CLI가 설치되어 있지 않으면 앱이 이를 표시하고, 필요한 경우 고급 설정의 기존 수동 연결 방식을 계속 사용할 수 있습니다.

## 더 쉬운 다계정 등록

Codex, Claude, Grok에서는 `+ 계정`을 누르면 앱이 별도의 로그인 디렉터리를 자동 생성한 뒤 해당 공급자의 공식 로그인 창을 엽니다.

사용자가 `CODEX_HOME`, `CLAUDE_CONFIG_DIR`, `GROK_HOME` 경로를 직접 입력할 필요가 없습니다. 기존에 수동으로 등록한 profile path도 그대로 유지됩니다.

OpenRouter의 `+ 계정`도 새 profile을 자동 생성한 뒤 OAuth 로그인으로 연결합니다.

## 자격증명 보안

- Codex/Claude/Grok 인증 파일을 앱이 복사하거나 교체하지 않음
- 공급자 CLI의 기존 인증 저장소를 그대로 사용
- OpenRouter OAuth callback은 **127.0.0.1에만** 연결
- OpenRouter OAuth에서 받은 API Key는 main process에서 즉시 Windows/Electron safeStorage 암호화 저장
- OpenRouter raw API Key를 설정 페이지로 반환하지 않음
- Copilot의 GitHub CLI 토큰은 메모리에서만 사용하고 앱 설정에 저장하지 않음
- 기존 OpenRouter localhost router의 fail-closed/no-replay 보안 정책 유지

## 기존 기능 유지

미니멀 설정으로 바뀌었지만 다음 기능은 그대로 남아 있습니다.

- 다계정 raw profile editor
- Smart Routing
- OpenRouter 다중 Key/Management Key
- localhost API Router
- GitHub PAT / Cursor cookie fallback
- edge dock
- 자동 reset
- 표시 방식/투명도/밀도/최대 높이

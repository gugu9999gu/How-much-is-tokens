# How much is tokens v1.0.28

## Windows 로그인 실행 오류 수정

설정 → 계정 연결에서 로그인/계정 추가 버튼을 눌렀을 때 Windows가 `\"...` 형태의 잘못된 실행 경로를 찾지 못한다는 오류를 표시하던 문제를 수정했습니다.

- `cmd.exe /c`에 전달하는 로그인 명령의 따옴표가 Node.js에서 다시 escape되지 않도록 Windows 인자를 verbatim으로 전달합니다.
- `where.exe`가 npm의 확장자 없는 POSIX shim과 `.cmd` shim을 함께 반환할 때, Windows에서 실제 실행 가능한 `.exe/.com/.cmd/.bat` 파일을 우선 선택합니다.
- 로그인 콘솔은 계속 표시되며 Codex, Claude, Grok, Cursor, Grok Bot, Copilot, Antigravity의 기존 로그인 흐름을 그대로 사용합니다.
- Windows command quoting과 npm shim 선택을 회귀 테스트에 추가했습니다.

## 포함 기능

v1.0.27까지의 생성형 미디어 API 공급자, 설정 UX 개선, 안전한 자격증명 저장, 다계정/Smart Routing 기능을 모두 포함합니다.

Windows portable 실행 파일과 `SHA256SUMS.txt`를 함께 배포합니다.

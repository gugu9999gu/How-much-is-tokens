# How much is tokens v1.0.34

## 한도, 리셋 쿠폰, 설치 버전, 결제 주기

- Claude 세션 한도를 5시간 한도로 표시하고, 남은 비율과 리셋 시각을 카드에 같이 보여 줍니다.
- Claude 리셋 쿠폰은 공식 OAuth 사용량 응답에서 읽습니다. 수량이 있으면 잔여 개수를 표시하고, 웹 화면에서만 보이는 쿠폰은 개수를 만들지 않고 웹에서 확인하라고 표시합니다.
- Codex 리셋 쿠폰은 사용량 응답의 잔여 수량을 표시하고, 상세 조회가 되면 가장 빠른 만료일도 함께 표시합니다. 이 버전은 쿠폰을 사용하지 않습니다.
- Codex, Claude, Grok, Cursor, Grok Bot, Copilot, Antigravity 카드에 설치된 CLI 버전을 표시하고, 더 새 버전이 있으면 업데이트 가능이라고 표시합니다.
- Cursor, Grok Bot, Copilot, Grok, ElevenLabs처럼 결제 또는 갱신 시각을 주는 플랫폼은 그 날짜를 표시합니다. OpenRouter는 선불이라 결제일이 없다고 표시합니다. 날짜가 없는 플랫폼은 결제일을 추정하지 않고 정보가 없다고 표시합니다.

Windows portable 실행 파일과 `SHA256SUMS.txt`를 함께 배포합니다.

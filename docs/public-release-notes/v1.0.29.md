# How much is tokens v1.0.29

## 위젯 사용성 개선

- 리셋 정보가 5초마다 `리셋까지 남은 시간`과 `리셋 예정 일시`로 번갈아 표시됩니다.
- 헤더에 미니멀한 엣지 숨김 패널 토글을 추가했습니다. 상/하/좌/우 위치 선택은 기존처럼 설정 화면에서만 변경합니다.
- 간단/자세히 모드가 사용량 새로고침 도중 오래된 설정값으로 되돌아가던 경쟁 조건을 수정했습니다.
- 위젯 테두리와 모서리를 드래그해 너비/높이를 직접 조정할 수 있고 선택한 크기를 유지합니다.

## CLI 버전과 업데이트

계정 연결 화면에서 설치된 Codex, Claude, Grok, Cursor, GitHub CLI, Antigravity CLI 버전을 확인할 수 있습니다. 확인 가능한 공식 최신 버전보다 오래된 CLI가 감지되고 해당 CLI가 자체 업데이트를 지원하면 `업데이트` 버튼을 표시합니다.

## 계정 연결 해제

- 연결된 계정별로 `해제` 컨트롤을 추가했습니다.
- Codex/Claude/Grok의 추가 프로필은 해당 프로필만 목록에서 제거하며 설정 디렉터리나 CLI 인증 파일은 삭제하지 않습니다.
- 기본 CLI 계정 연결 해제는 위젯에서만 비활성화하며 CLI 자체 로그인 정보는 유지합니다.
- OpenRouter 연결 해제는 선택한 프로필의 앱 보안 저장소 키를 삭제합니다.

기존 생성형 미디어 API, Smart Routing, 엣지 숨김 패널 및 안전한 자격증명 저장 기능은 그대로 유지합니다.

# How much is tokens v1.0.35

## Grok 잔여량 상시 표시

- Grok CLI 액세스 토큰이 몇 시간 뒤 만료되어도, 저장된 갱신 토큰으로 세션을 자동 갱신하고 잔여량을 계속 조회합니다.
- 갱신이 실패해도 로그아웃으로 카드를 숨기지 않고, 마지막으로 확인한 잔여량을 유지합니다.
- 프로그램을 몇 시간 쓰지 않아도 Grok 잔여량 카드가 사라지지 않습니다.

## 카드 정보 정리

- 리셋 쿠폰, 결제·구독, 설치 CLI 버전을 한 줄 알약 대신 칸으로 나눠 표시합니다.
- 결제일이 로그인 정보로 오지 않는 플랫폼은 날짜를 추정하지 않고 정보 없음으로 표시합니다.
- Antigravity 사용량 조회 대기 시간을 늘려 5시간·주간 한도가 비어 보이지 않게 했습니다.

Windows portable 실행 파일과 `SHA256SUMS.txt`를 함께 배포합니다.

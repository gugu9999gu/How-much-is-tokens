# How much is tokens v1.0.37

## Claude 사용량 자동 갱신

- Claude 액세스 토큰이 몇 시간 뒤 만료되어도, 저장된 갱신 토큰으로 세션을 자동 갱신하고 사용량을 계속 조회합니다.
- 갱신이 실패해도 리프레시 토큰을 지우지 않고, 마지막으로 확인한 사용량을 유지합니다.
- 다시 로그인하지 않아도 5시간 한도와 주간 한도가 이어집니다.

## 결제일이 없을 때

- 결제일을 주지 않는 플랫폼은 5시간 창을 결제일로 쓰지 않습니다. 주간 또는 월간 한도 중 가장 빠른 갱신일을 한도 갱신으로 표시합니다.
- 구독 시작일로 다음 청구일을 추정하지 않습니다. 결제일이 있는 플랫폼은 기존 날짜를 유지합니다.

Windows portable 실행 파일과 `SHA256SUMS.txt`를 함께 배포합니다.

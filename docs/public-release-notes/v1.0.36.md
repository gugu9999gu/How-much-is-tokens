# How much is tokens v1.0.36

## 스마트 라우팅과 Codex 리셋 쿠폰

- Windows npm 설치의 `codex.cmd`는 app-server를 바로 종료해, Codex 한도 자동 리셋이 서버의 한도 도달 여부를 보지 못했습니다. 이제 실제 `codex.exe`로 조회하고, 필요하면 쿠폰을 사용합니다.
- 자동 사용은 계속 기본 꺼짐입니다. 켠 계정에서 서버가 실제 `rate_limit_reached`를 보고하고 사용 가능한 쿠폰이 있을 때만 1장을 쓰며, 같은 한도 구간에서 다시 쓰지 않습니다.
- Smart Routing 저장이 Cursor, Copilot, Antigravity 정책을 지우지 않도록 고쳤습니다.
- Claude 리셋 쿠폰은 claude.ai 웹 전용이라 이 앱이 자동으로 사용하지 않습니다. Grok CLI에는 리셋 쿠폰 사용 API가 없습니다.

Windows portable 실행 파일과 `SHA256SUMS.txt`를 함께 배포합니다.

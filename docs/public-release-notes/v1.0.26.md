# How much is tokens v1.0.26

## 생성형 미디어 API 공급자 추가

API 키만 저장하면 남은 사용량·크레딧 잔액·최근 생성 로그를 위젯 카드로 함께 볼 수 있는 공급자를 추가했습니다.

- **fal.ai**: 계정 크레딧 잔액
- **Higgsfield**: API Key ID/Secret 저장 (공개 잔액 API가 제한적이라 잔여 크레딧은 확인 가능한 경우에만 표시)
- **Magnific / Freepik**: 최근 생성 로그(사용 현황)
- **ElevenLabs**: 월간 문자 사용량 %
- **Stability AI**: 크레딧 잔액

설정 → `생성형 미디어 API`에서 각 공급자의 키를 저장하면 카드가 활성화됩니다. 공급자마다 공개 API가 실제로 제공하는 항목만 표시하며, 없는 값은 추정하지 않습니다.

## 더 직관적인 설정 화면

고급 설정을 한 덩어리 대신 **접기/펼치기 가능한 섹션 목록(아코디언)**으로 재구성했습니다.

- 각 섹션은 아이콘 + 제목 + 한 줄 설명으로 표시되어 원하는 항목을 바로 찾아 열 수 있습니다.
- 표시 · 화면 가장자리 · 다계정 프로필 · Smart Routing · 자동화 · 동기화 · API 공급자 · 생성형 미디어 API · 연결을 개별적으로 펼칠 수 있습니다.
- 프로필 목록 입력란에 `provider | 표시 이름 | 경로` 형식을 시각적으로 보여주는 라벨을 추가해 입력 형식을 한눈에 파악할 수 있습니다.
- 모든 설정 컨트롤에 일관된 키보드 포커스 표시를 적용하고, 제목 표시줄 버튼과 설정 열기 상태에 접근성 라벨을 추가했습니다.

## 안정성 수정

- 고급 설정 패널이 열릴 때 내용이 표시되지 않던 레이아웃 문제(설정 영역이 flex 컨테이너일 때 `<details>` 높이가 접히던 현상)를 수정했습니다.

## 자격증명 보안

- 생성형 미디어 API 키 원문은 `settings.json`에 저장하지 않고 기존 OpenRouter 키와 동일하게 OS 보안 저장소(safeStorage)에 암호화합니다.
- 저장 가능한 시크릿 이름을 화이트리스트로 제한하고, 공급자 정의에 선언된 자격증명 필드만 저장합니다.
- 외부 API에서 받은 로그/텍스트는 화면에 표시하기 전에 이스케이프합니다.

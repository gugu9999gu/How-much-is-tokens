# How much is tokens v1.0.47

## The X Subscription 목록가

Cursor, Grok, Grok Bot의 통합 요금제 The X Subscription 목록가를 카드에 표시합니다. 금액은 2026-10-26 공식 목록가입니다.

- Free: $0. 포함 사용량은 Limited입니다. Grok Bot은 포함되지 않습니다.
- Plus: 월 $8, 연 $80(월 $7). 포함 사용량은 Base입니다. Grok Bot은 포함되지 않습니다.
- Premium: 월 $30, 연 $300(월 $25). 포함 사용량은 4x Plus입니다. Grok Bot은 공유 주간 한도에 포함됩니다.
- Super: 월 $100, 연 $1000(월 $84). 포함 사용량은 15x Plus입니다. Grok Bot은 공유 주간 한도에 포함됩니다.

Plus, Premium, Super에서는 서드파티 모델을 포함 한도인 Other Models로 계산하지 않습니다. 포함량을 넘는 사용은 On-demand가 아니라 추가 사용입니다.

Ultra의 사용량 모델은 바꾸지 않았습니다. 레거시 Cursor Ultra와 X Subscription Ultra가 둘 다 월 $200이라, 이름만으로 주간 공유 풀이나 50x Plus를 적용하지 않습니다. X Subscription Ultra의 연 $2000(월 $167)과 포함 50x Plus는 그 구분이 생기기 전에는 카드에 붙이지 않습니다.

SuperGrok, SuperGrok Plus, SuperGrok Heavy, SuperGrok Lite의 개별 가격은 공식 목록에 없어 만들지 않았습니다. SuperGrok Lite만 Grok Bot 미포함으로 표시합니다.

주간 공유 풀의 퍼센트 필드는 공식 문서가 `usage-summary` 필드명을 주지 않아 합성하지 않았습니다. API가 주는 Cursor Models 퍼센트와 금액은 그대로 둡니다.

레거시 Cursor 목록가도 구분합니다. Hobby $0, Start 월 ₹649(세금 포함), Pro 월 $20, Pro+ 월 $60, Teams Standard 월 $40/인, Teams Premium 월 $120/인. Pro와 Pro+는 Cursor Models, Other Models, On-demand를 유지합니다.

Windows portable 실행 파일과 `SHA256SUMS.txt`를 함께 배포합니다.

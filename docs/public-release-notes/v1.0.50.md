# How much is tokens v1.0.50

## Claude 다계정 Fable 한도 표시 개선

- Claude 계정별 사용량의 `limits[]`, `model_scoped[]`, `rate_limits.model_scoped[]` 응답 형식을 모두 지원하여 Fable 주간 한도가 누락되는 문제를 수정했습니다.
- 각 계정의 개별 OAuth 인증과 사용량 응답을 사용하며, 서로 다른 프로필의 Fable 잔여량이 섞이지 않도록 회귀 테스트를 추가했습니다.
- Fable 한도가 구조화된 응답과 기존 호환 필드에 중복 포함되면 동일한 모델별 한도를 한 번만 표시합니다.
- Fable 사용량이 제공되지 않으면 0% 또는 100%를 임의로 만들지 않고 상태를 명시합니다.
- Pro 플랜은 Fable 별도 구독 주간 한도가 아니라 사용량 크레딧을 쓰는 경우가 있어 이를 안내합니다. Max·Ultra 플랜에서 API가 모델별 한도를 반환하지 않는 경우에도 조회 누락 상태를 명시합니다.
- 기존 5시간·주간·모델별 한도, 다른 AI 제공자, 다계정 설정은 유지합니다.

# How much is tokens v1.0.31

## 계정 자동화 확장

- Codex, Claude, Grok에 이어 Cursor와 Copilot도 격리된 추가 계정 연결을 지원합니다.
- Grok Bot은 Cursor 계정 프로필을 공유해 계정별 사용량을 함께 표시합니다.
- 인증된 계정이 중복으로 추가되면 fresh account identity를 확인한 뒤 중복 프로필을 제거합니다.
- Antigravity는 기존 `agy` 단일 계정을 그대로 지원하며, 선택적 계정 도우미를 설치한 경우 여러 Google 계정을 추가·조회·전환할 수 있습니다.

## Smart Routing 확대

- Codex / Claude / Grok / Cursor / Copilot / Antigravity에서 새 CLI 실행 시 계정을 자동 선택할 수 있습니다.
- `1번 소진 → 다음 계정`, `잔여량 가장 많은 계정`, `기본 계정 고정` 정책을 지원합니다.
- 오래된 사용량, 최근 조회 실패, 한도 도달, 알 수 없는 quota는 자동 선택에서 제외합니다.
- 터미널용 `*-auto.cmd` 런처도 6개 공급자로 확대했습니다.
- 이미 실행 중인 CLI 세션의 인증은 중간에 바꾸지 않습니다.

## Codex 추가 계정 reset ticket

- 기본 Codex 계정의 기존 자동 reset 기능을 유지합니다.
- 추가 Codex 계정은 각 프로필별 토글을 명시적으로 켠 경우에만 banked reset ticket을 자동 사용합니다.
- 실제 서버의 rate-limit 도달 확인, ticket 존재 확인, 만료 임박 ticket 우선, 중복 소비 방지 조건을 유지합니다.

## CLI 버전 및 업데이트

- 설치된 AI CLI 버전과 확인 가능한 최신 버전을 연결 카드에서 표시합니다.
- Codex, Claude, Grok, Cursor, Copilot, Antigravity의 공식 updater/설치 방식을 사용하며, 설치 방식을 안전하게 판별할 수 없는 경우 업데이트 버튼을 노출하지 않습니다.
- Copilot은 최신 standalone `copilot` CLI를 기준으로 동작합니다.

## 리셋 시간 표시 설정

- `자동`: 남은 시간과 리셋 예정 일시를 5초마다 전환
- `남은 시간`: 카운트다운으로 고정
- `예정 일시`: 실제 날짜/시간으로 고정

기존 반응형 토큰 그리드, 자유로운 창 크기 조절, 엣지 숨김 패널, 계정 이메일/ID 표시, 연결 해제 및 OpenRouter localhost failover 기능도 그대로 유지됩니다.

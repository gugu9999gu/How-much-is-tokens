# v1.0.48

라이브 응답이 `isUnifiedBillingUser` 또는 `isUnified`이면 Cursor, Grok, Grok Bot을 X Subscription 카드 한 장으로 합친다. 이 PC 계정은 Premium, 공유 주간 풀, 포함 제품 Cursor · Grok · Grok Bot으로 확인했다. 플래그가 없는 레거시 계정은 카드를 나누어 둔다.

공개 노트는 `docs/public-release-notes/v1.0.48.md`를 사용한다. 공개 저장소에는 Windows portable 실행 파일, `SHA256SUMS.txt`, 그 공개 노트만 올린다.
